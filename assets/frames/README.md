# iPhone frame

[iphone.svg](iphone.svg) contains the physical iPhone frame from
[`@sneas/telephone` 1.2.0](https://github.com/sneas/telephone), also used by Whip's
README mockups. Its synthetic status bar and camera island were removed so the
actual simulator capture supplies those details. The original frame is named
`iphone-16-max`; the mockup generator fits its opening to our iPhone 17 Pro
captures without stretching the app UI.

The frame is distributed under the [MIT license](LICENSE). It is used only to
generate documentation images.
